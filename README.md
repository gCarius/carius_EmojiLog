# 😃 EmotiLog – An Emoji Mood Tracker
A lightweight Android app that lets users track their daily moods using emojis. Designed with a clean UI and simple interactions, EmotiLog makes it fun and easy to reflect on emotions over time.

# 🚀 Features
	•	📅 Log moods quickly using a set of 9 expressive emojis
	•	📊 Daily summary with total counts and frequency breakdowns
	•	🕒 Timestamped entries for detailed tracking
	•	📈 Visual graphs to see mood trends over days/weeks

# 🛠️ Built With
	•	Android Studio – development environment
	•	Java – primary programming language
	•	MVVM Architecture – separation of concerns using ViewModel + LiveData
	•	Room Database – local storage for mood entries
	•	XML UI + ViewBinding – responsive layouts

# 🧠 What I Learned
	•	Building a full Android app from scratch with Java
	•	Structuring code with MVVM and shared ViewModels across fragments
	•	Designing UML diagrams for fragments, activities, and data flow
	•	Implementing daily summaries with counts and frequency calculations
	•	Generating APK builds for distribution and testing
